# Fiscal Lens — 市町村財政ダッシュボード

市町村の財政指標を、全国・類似団体・県内の3つの視点から比較する静的Webアプリです。現在のリポジトリはUIと操作設計を検証するプロトタイプで、数値はデモデータです。公式値として引用しないでください。

## 実装済み画面

- 全国ランキング：都道府県・類似団体区分・人口・指標で絞り込み、CSV出力
- 指標マップ：任意の2指標を組み合わせた散布図、団体検索とハイライト
- 団体カルテ：主要6指標、類似団体差、推移、経常収支比率の内訳、主因表示
- 和歌山ビュー：県内30市町村のヒートマップと直近3年の悪化幅抽出
- やさしい指標解説：6指標の計算方法、具体例、読み方、用語集
- 出典・注意：データ系統、指標定義、言えること／言えないこと、加工フロー

画面の選択・年度・指標・団体はURLパラメータに保存されます。ランキング表と和歌山ビューは表示データをCSVで保存できます。

## ローカル起動

前提：Node.js 22.13.0以上

```bash
npm install
npm run dev
```

本番ビルド：

```bash
npm run build
```

## データ差し替え

デモデータは `app/data.ts` にあります。実データ接続時は、前処理済みJSONを `public/data/` に配置し、`Dashboard.tsx` から取得する構成へ移行してください。表示用スキーマは次の列を前提にしています。

```text
code, name, pref, group, population,
fiscalStrength, ordinaryBalance, debtService,
futureBurden, fundBalance, personnel, trend, cause
```

実データ公開前に、少なくとも次を確認してください。

1. 団体コードが5桁であること
2. 対象年度ごとの団体数・欠損数が説明できること
3. 健全化判断比率の「—」を欠損と混同していないこと
4. 東京23区・合併団体の扱いが注記と一致すること
5. 和歌山市・北山村など特徴の異なる団体を公表値と照合すること

## 技術構成

- Next.js互換のVinext + React + TypeScript
- Cloudflare Worker互換の静的配信構成
- 外部チャート依存なし（軽量なCSSベースの可視化）
- レスポンシブ対応、キーボードフォーカス、色だけに依存しない値表示

元の要件定義は一つ上のフォルダにある `市町村財政ダッシュボード_要件定義_v0.1.md` を参照してください。
